# マッキンゼー流・批判的レビューチェックリスト（references/critic-checklist.md）

「深夜2時のエンゲージメントマネージャー（EM）」の視点で、骨子・ストーリーラインの論理の穴、飛躍、詰めの甘さを徹底的に洗い出すためのチェックリストです。

---

## 1. 判定グレード（Overall Verdict）

| グレード | 状態と基準 | アクション |
| :--- | :--- | :--- |
| **🟢 GREEN** | ステークホルダー（CEO・役員）へ提示可能。論理・データ・主張が完璧に接地している。 | 最終の微細な表現調整のみ行い、スライド化へ進む。 |
| **🟡 YELLOW** | 思考の方向性は正しいが、構造的な穴や「So What?」の弱さがある。このまま出してはならない。 | 最優先のTop 3修正点を今夜中に修正する。 |
| **🔴 RED** | 根底の論理が破綻している、または作業報告になっている。要再構築。 | S-C-P-Rの問い（Problem）から再定義する。 |

---

## 2. 重点検査項目（4大チェック）

### ① 構造とナラティブ（Structure & Flow）
- [ ] **Headline-Flow**: タイトルだけを上から順に通読して、1本のストーリーとして意味が繋がるか？
- [ ] **結論先行**: 「私たちは〜を調べた」ではなく、「〜という結論に至った」と結論が冒頭に来ているか？
- [ ] **章の配置順序**: 「課題」のセクションに解決策が紛れ込んでいないか？「解決策」の後に新たな課題が出てきていないか？

### ② 厳密性とデータ接地（Rigor & Evidence）
- [ ] **数字の具体性**: 「大幅に増加」「急速に拡大」などの曖昧な形容詞を排除し、「前年比+24%」「月間2,000時間」などの具体的数値が入っているか？
- [ ] **出典の明記**: すべての主要な主張・市場数値・コスト試算に出典（一次情報、ヒアリング調査、公的統計）が付記されているか？
- [ ] **公平な比較**: 競合比較において自社に都合の良い軸だけで比較していないか？競合の強みもフェアに扱っているか？

### ③ So What?（示唆と行動）
- [ ] **示唆の有無**: 単なるグラフや事実の陳述にとどまらず、「だからクライアントは何をすべきか（含意）」が書かれているか？
- [ ] **アクションの明確性**: 推奨施策は「リソースを配分する」「推進を検討する」ではなく、「初期投資4,500万円を投じ、6ヶ月で8拠点を統合する」のように、主語・金額・期日が明確か？
- [ ] **判断の強制**: 役員や意思決定者が「Yes」か「No」を言える形の論点になっているか？

### ④ 網羅性と反論耐性（MECE & Stress-test）
- [ ] **MECE性**: 施策の柱に明らかな重複や抜け漏れ（「セキュリティはどうするのか？」「現場の運用コストは？」等）がないか？
- [ ] **反手（反論）への備え**: 最も手厳しい役員から「なぜ内製ではなく外部調達なのか？」「投資回収が遅れた場合のリスクは？」と突っ込まれたときの防壁があるか？

| スライド番号 | 判定 | 指摘事項・論理の穴 |

| S02 要約 | 🟡 YELLOW | 結論は明快だが、3年目の黒字化根拠が不足 |
| S03 課題 | 🔴 RED | トピックタイトル病。「現状課題」ではなく「入力重複により2.4万時間の過剰工数が発生」と言い切るべき |

## Top 3 改善アクション（優先度順）

2. **[改善2]**: [問題点と具体的な修正手順]
3. **[改善3]**: [問題点と具体的な修正手順]
