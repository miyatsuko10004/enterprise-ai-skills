# コンサルティング・ストーリーライン実践テンプレート集（references/storyline-templates.md）

本ドキュメントは、マッキンゼー・BCG・Bain等の戦略コンサルティングファーム水準のプレゼンテーション骨子を構築するための実戦テンプレート集です。
すべてのテンプレートは、**ピラミッド原則（Answer-First）**、**SCPR構造**、および `consulting-pptx-skill` の **62型カタログ** と完全連動しています。

## テンプレート1: 戦略提案・新規事業（Market-to-Strategy Arc）
> **目的**: 市場機会と自社ケイパビリティを証明し、事業参入・投資の意思決定を得る。
> **構成枚数**: 8〜12枚

### 【骨子設計】
- **Tagline**: 「〇〇市場への早期参入と××社提携により、3年で△△億円の高収益事業を確立する」
- **SCPR構造**:
  - **Situation**: 対象市場は年率XX%で急拡大しており、法改正/AI普及により構造変化が進行中。
  - **Complication**: 既存プレイヤーはレガシー構造に縛られ顧客の真のニーズを満たせていない。
  - **Problem**: 自社はどのようなポジショニングとアライアンスで先行者利益を獲得すべきか？
  - **Recommendation**: 独自の××アセットをテコに垂直統合モデルを構築し、フェーズ1で〇〇億円投資する。

```markdown
### [S01] 表紙
- 型ID: b01 (title_page)
- タイトル: [事業名] 参入戦略および事業計画書
- サブタイトル: 独自の技術優位性を活かした3年後の売上50億円達成ロードマップ

### [S02] エグゼクティブサマリー
- 型ID: m01 (executive_summary)
- アクションタイトル: 対象市場の急拡大を背景に、当社技術とパートナー網の融合により3年で営業利益15億円を創出する
- 論拠/柱:
  1. 成長市場の空白地帯: 年25%成長の〇〇市場において、中堅企業向け特化ソリューションが不在
  2. 圧倒的な参入障壁: 自社特許アルゴリズムにより競合比で処理コストを60%削減可能
  3. 段階的投資回収: 2億円の初期投資で18ヶ月で単年度黒字化、3年でROI 240%を達成

### [S03] 市場環境
- 型ID: b24 (scenario_lines_cagr)
- アクションタイトル: 〇〇市場は年率24%で急成長しており、2030年には3,000億円規模に達する見込みである
- 論拠/ファクト:
  - 国内市場規模は現在1,200億円、規制緩和に伴い年率24%ペースで拡大
  - 特に「業務自動化・コンプライアンス対応」領域への需要が全体の65%を占める
- 出典: IDC Japan 国内市場予測レポート（2025年版）

### [S04] 競合状況・顧客の未充足ニーズ
- 型ID: b09 (axis_table)
- アクションタイトル: 既存大手ベンダーは高価格・長期導入に偏重しており、中堅企業の導入要件を満たせていない
- 論拠/ファクト:
  - 大手A社・B社は導入期間平均12ヶ月、初期費用5,000万円超でSMB/中堅には過大
  - 顧客ヒアリング20社中18社が「即座に稼働する軽量・定額モデル」を強く要望
- 出典: 自社顧客ヒアリング調査（n=20、2026年1月）

### [S05] 当社の提供価値とポジショニング
- 型ID: b11 (claim_panel_figure)
- アクションタイトル: 当社はクラウドネイティブな即時提供基盤により、大手の1/3の価格で同等の機能を実現する
- 論拠/ファクト:
  - 導入リードタイムを従来の12ヶ月から最短2週間に短縮
  - 月額定額課金モデルにより導入ハードルを極小化し、LTV/CAC比率 4.5倍を確保

### [S06] 事業構造・エコシステム
- 型ID: b02 (overview_map)
- アクションタイトル: 販社パートナーとのアライアンスにより、営業費用を抑制しながら全国顧客へ最短浸透を図る
- 論拠/ファクト:
  - 大手販売代理店3社との提携基本合意により、開拓初年度から500社の見込み顧客にリーチ可能
  - パートナー向けレベニューシェア20%を設定し、積極的な拡販インセンティブを付与

### [S07] 収益シミュレーション
- 型ID: m07 (waterfall)
- アクションタイトル: 初年度1.5億円の先行投資を要するものの、3年目には売上30億円・営業利益8億円を見込む
- 論拠/ファクト:
  - 1年目: プロダクト磨き込みとパイロット30社導入（売上1.2億円、営業損失0.8億円）
  - 2年目: 代理店展開本格化（売上8.5億円、営業利益1.5億円で黒字化）
  - 3年目: アップセル・周辺機能拡張（売上30億円、営業利益率27%）

### [S08] 実行計画・マイルストーン
- 型ID: b05 (chevron_steps)
- アクションタイトル: 3フェーズの移行計画を策定し、Q2のMVPローンチに向けて直ちに体制構築を開始する
- 論拠/ファクト:
  - Phase 1 (1〜3ヶ月): MVP開発完了・パイロット導入開始（Owner: プロダクト責任者）
  - Phase 2 (4〜6ヶ月): 代理店契約締結・正式ローンチ（Owner: 営業統括）
  - Phase 3 (7〜12ヶ月): 全国展開・機能拡充（Owner: 事業本部長）

### [S09] 投資要請・決定事項
- 型ID: b06 (premise_conclusion)
- アクションタイトル: 初年度開発・マーケティング予算2億円の承認、および推進専任組織の組成を要請する
- 論拠/ファクト:
  - 意思決定事項: 2026年度上期投資枠2.0億円の拠出承認
  - 組織体制: 事業推進リーダー1名、テックリード1名、外部コンサルタントの専任配置
```

## テンプレート2: 課題解決・業務改革（Problem-to-Solution Arc）
> **目的**: 業務上のボトルネックや損失要因を特定し、構造改革施策と期待効果を提示する。
> **構成枚数**: 7〜10枚

### 【骨子設計】
- **Tagline**: 「基幹業務の自動化とプロセス標準化により、年間2.4万時間の工数削減と品質向上を両立する」

```markdown
### [S01] 表紙
- 型ID: b01 (title_page)
- タイトル: [業務名] 抜本改革プランおよび実行構想
- サブタイトル: 業務プロセスの可視化に基づく生産性向上と年間8,000万円のコスト適正化

### [S02] エグゼクティブサマリー
- 型ID: m01 (executive_summary)
- アクションタイトル: 属人化と重複入力に起因する年間2.4万時間の過剰工数を、3つの改革レバーにより60%削減する
- 論拠/柱:
  1. 課題の本質: 各拠点ごとの個別業務手順と転記作業が業務時間の42%を占有
  2. 打ち手の骨子: 入力の一元化、ワークフロー自動化、拠点間オペレーション統合
  3. 定量効果と投資: 年間8,000万円の削減効果に対し、初期投資4,500万円（回収期間7ヶ月）

### [S03] 現状の課題構造
- 型ID: b26 (issue_action_columns)
- アクションタイトル: 現行業務は手作業による二重三重の転記が発生しており、月間2,000時間のムダが生じている
- 論拠/ファクト:
  - 拠点間でのExcel受け渡しが月間1,200回発生し、転記ミスによる手戻りが全体の18%を占める
  - 繁忙期における残業時間は1人当たり月45時間を超過し、離職の主因となっている
- 出典: 業務時間トラッキング調査（全8拠点、対象者140名）

### [S04] ボトルネックの真因分析
- 型ID: b13 (status_heatmap_comment)
- アクションタイトル: 拠点ごとに独自帳票が温存されていることが標準化を阻む根本要因である
- 論拠/ファクト:
  - 共通業務であるはずの発注処理において、拠点固有ルールが計48件残存
  - 本社システムと現場Excelのマスター不整合が月間200件超のエラーを誘発

### [S05] 改革の基本方針と3つのレバー
- 型ID: b19 (pillars_foundation)
- アクションタイトル: 標準帳票への一本化と自動連携ツールの導入により、人的介入を最小化する
- 論拠/ファクト:
  - レバー1 (標準化): 全拠点共通の統一業務フローへの強制移行
  - レバー2 (自動化): OCRおよびAPI連携による転記・照合作業の全自動化
  - レバー3 (集約化): 例外処理を専門とするシェアードサービスセンターの設置

### [S06] 定量効果の試算（コスト削減ブリッジ）
- 型ID: m08 (true_waterfall)
- アクションタイトル: 施策の全面適用により、年間総人件費の25%に相当する8,200万円の削減を実現する
- 論拠/ファクト:
  - 転記削減: ▲3,400万円 / 手戻り解消: ▲2,600万円 / 拠点集約効果: ▲2,200万円
  - 創出された余力時間は高付加価値な顧客提案業務へ再配置

### [S07] 移行ロードマップと推進体制
- 型ID: b05 (chevron_steps)
- アクションタイトル: パイロット拠点での3ヶ月検証を経て、6ヶ月で全8拠点への水平展開を完了する
- 論拠/ファクト:
  - 1〜3ヶ月目: 本社およびモデル拠点Aでの新フロー試行とマニュアル策定
  - 4〜6ヶ月目: 残り7拠点への順次展開、旧帳票の完全廃止
```

  - 次のアクション: 変更契約書の締結（10/15迄）および結合テスト計画書の確定（10/20迄）

## ストーリーライン構築時のセルフチェック質問（Headline-Flow Test）

各スライドのタイトルを書いた後、以下の3つの質問でストレステストを行ってください：
1. **「タイトルだけを読み上げて、ストーリーが流れているか？」**
   （タイトルだけを繋げて1つの文章として読んだ時に、前後のつながりが自然か）
2. **「体言止めや名詞ラベルになっていないか？」**
   （「〇〇の検討」ではなく、「〇〇に向けて××を導入する」と結論を言い切っているか）
3. **「なぜその型ID（ビジュアル）なのかが自明か？」**
   （対比なら2カラム、変化ならウォーターフォール、手順なら矢羽など、タイトルを証明する適切な図法が選ばれているか）
